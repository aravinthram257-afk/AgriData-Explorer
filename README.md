# 🌾 AgriData Explorer

## Project Overview
AgriData Explorer is an interactive data analytics platform for analyzing Indian agricultural production, yield, and cultivation area using Python, SQL, and Power BI.

## Tech Stack
- Python
- Pandas
- Streamlit
- SQL (MySQL)
- Power BI

## Features
- 50-Year Crop Production Analysis
- Top Producing States
- Yield Comparison
- Area vs Production Correlation
- 10 SQL Analytical Queries
- Interactive Dashboard

## How to Run
pip install -r requirements.txt
streamlit run app.py
